# Asset sources

The seed and public templates use bundled illustrative images downloaded from Unsplash, under the [Unsplash license](https://unsplash.com/license), which permits free commercial and noncommercial use. These are illustrative licensed stock photographs, not scraped real estate listings. The application does not republish records from Zillow, Redfin, Compass, or Realtor.com. Before a public launch, review any property/model/trademark releases required for the intended use and substitute actual authorized listing photographs.

Image identifiers used: `photo-1600596542815-ffad4c1539a9`, `photo-1600210492486-724fe5c67fb0`, `photo-1600607687920-4e2a09cf159d`, `photo-1600047509807-ba8f99d2cdde`, `photo-1600566753190-17f0baa2a6c3`, `photo-1600607687939-ce8a6c25118c`, `photo-1518837695005-2083093ee35b`, `photo-1580489944761-15a19d654956`, `photo-1500648767791-00dcc994a43e`, `photo-1534528741775-53994a69daeb`.

No real identity, agency credential, testimonial, or transaction is inferred from a stock portrait. Profile copy labels each seeded agent fictional. Demo profiles are initially unverified; an explicit admin verification action is required for a badge, which remains labeled as a demo profile.

Fonts are Playfair Display and DM Sans served by Google Fonts; both families use the SIL Open Font License. Photographs are bundled locally in public/assets/photos; Google Fonts requires network access. System serif and sans-serif fallbacks are included. The favicon and monogram are original SVG/CSS assets created for this project.
